# 🌬️ Naseem | نسيم

Telegram Bot for Arabs in Germany  
Daily weather + prayer times + smart advice.

## Features
- Daily message
- City-based
- Weather + Salah
- Arabic friendly

## Tech Stack
- Python
- python-telegram-bot
- Open-Meteo API
- Aladhan API

## Setup
1. Clone repo
2. Create `.env`
3. Add BOT_TOKEN
4. Run `python bot.py`
